# BlurStudio

ابزار مینیمال برای بلور / پیکسلی / رنگی کردن بخش‌های حساس ویدیو (مخصوص ضبط‌های صفحه مثل OBS).

## امکانات (نسخه ۰.۱ — حالت دستی)
- رها کردن (Drag & Drop) ویدیو روی برنامه؛ پخش روان حتی برای ویدیوهای چندساعته (دیکود سخت‌افزاری)
- کشیدن مستطیل / مربع (Shift) و بیضی / دایره (Shift)
- هر شکل یک ردیف در تایم‌لاین با دستگیره‌ی شروع و پایان؛ کشیدن دستگیره، ویدیو را دقیقاً به همان فریم می‌برد
- حالت بلور، پیکسلی یا رنگ برای هر مورد + شدت قابل تنظیم
- لیست موارد و پنل جزئیات در سمت راست (قابل مخفی شدن با H)
- برگشت/جلو (Ctrl+Z / Ctrl+Y)، ذخیره و باز کردن پروژه (.blurproj)
- خروجی MP4 با FFmpeg، با انکودر کارت گرافیک (NVENC / QuickSync / AMF) و برگشت خودکار به CPU؛ صدا بدون تغییر کپی می‌شود

## میانبرها
Space پخش · ←/→ یک فریم · Shift+←/→ یک ثانیه · I / O تنظیم شروع/پایان روی زمان فعلی · Del حذف · V/R/E ابزارها · H پنل · Ctrl+چرخ موس زوم تایم‌لاین · Ctrl+D کپی مورد

## اجرا از سورس
```bash
npm install
# ffmpeg را در PATH داشته باشید یا ffmpeg.exe را در پوشه bin/ بگذارید
npm start
```

## ساخت EXE ویندوز
```bash
# ffmpeg.exe (مثلاً از https://github.com/BtbN/FFmpeg-Builds) را در bin/ بگذارید
npm run dist
```
